01URLSession async

URLSession native sudah cukup untuk mayoritas kebutuhan. API async menggantikan completion handler & delegate untuk request standar.

Old → New · HTTP request
Old — dataTask + handler 
URLSession.shared.dataTask(
  with: url) { data, resp, err in
    if let err { return }
    guard let data else { return }
    // parse di dalam closure
}.resume()
New — async/await 
let (data, resp) = try await
    URLSession.shared.data(from: url)
// linear, throws,
// otomatis cancellable
Migrasi: Ganti dataTask(...).resume() dengan try await session.data(from:) / data(for:). Alasan: versi async mengintegrasikan error ke throws, mendukung cancellation structured concurrency (Module 3), dan menghapus closure bersarang. Delegate-based session tetap dipakai untuk streaming, background download, atau metrics.

GET & POST dengan URLRequest
func get<T: Decodable>(_ url: URL) async throws -> T {
    var req = URLRequest(url: url)
    req.httpMethod = "GET"
    req.setValue("application/json", forHTTPHeaderField: "Accept")
    let (data, resp) = try await URLSession.shared.data(for: req)
    try validate(resp)
    return try JSONDecoder().decode(T.self, from: data)
}

func post<Body: Encodable, T: Decodable>(_ url: URL, body: Body) async throws -> T {
    var req = URLRequest(url: url)
    req.httpMethod = "POST"
    req.setValue("application/json", forHTTPHeaderField: "Content-Type")
    req.httpBody = try JSONEncoder().encode(body)
    let (data, resp) = try await URLSession.shared.data(for: req)
    try validate(resp)
    return try JSONDecoder().decode(T.self, from: data)
}
Catatan arsitekturKode di atas adalah NetworkService level terendah. Di Phase 5 (Module 10) ia dibungkus interceptor (auth/refresh/retry) dan diabstraksi sebagai protocol agar dapat di-mock saat testing. Jangan panggil URLSession langsung dari ViewModel di kode produksi.

02Codable

Codable = Encodable & Decodable. Mayoritas model cukup conform tanpa kode tambahan. Kontrol detail lewat CodingKeys dan strategy.

struct Order: Codable, Identifiable {
    let id: String
    let totalAmount: Decimal
    let createdAt: Date
    let items: [Item]                        // nested otomatis

    enum CodingKeys: String, CodingKey {
        case id
        case totalAmount = "total_amount"    // mapping snake_case → camelCase
        case createdAt = "created_at"
        case items
    }
}

let decoder = JSONDecoder()
decoder.dateDecodingStrategy = .iso8601      // tangani tanggal di satu tempat
// Alternatif global: decoder.keyDecodingStrategy = .convertFromSnakeCase
Pilihan strategiUntuk API konsisten snake_case, keyDecodingStrategy = .convertFromSnakeCase menghapus kebutuhan CodingKeys manual. Gunakan CodingKeys eksplisit hanya saat mapping tidak seragam. Untuk Decimal uang, hindari Double (presisi floating-point merusak nilai moneter).

03Response Validation & Error Model

Jangan pernah mendecode body tanpa memvalidasi status HTTP. Definisikan error domain yang typed.

enum APIError: Error, Equatable {
    case invalidResponse
    case unauthorized                 // 401 → trigger refresh (Module 10)
    case notFound
    case server(status: Int)
    case decoding(String)
}

func validate(_ resp: URLResponse) throws {
    guard let http = resp as? HTTPURLResponse else { throw APIError.invalidResponse }
    switch http.statusCode {
    case 200...299: return
    case 401:       throw APIError.unauthorized
    case 404:       throw APIError.notFound
    case 500...599: throw APIError.server(status: http.statusCode)
    default:        throw APIError.server(status: http.statusCode)
    }
}
PrinsipError domain yang typed (bukan Error generik) memungkinkan ViewModel bereaksi spesifik: .unauthorized memicu refresh token, .notFound menampilkan empty state, .server menampilkan retry. Petakan error transport (offline, timeout) secara terpisah dari error HTTP.

04Keychain — Secure Storage

Token autentikasi wajib di Keychain, bukan UserDefaults (yang plaintext). Keychain terenkripsi dan dapat diikat ke biometrik.

import Security

enum Keychain {
    static func save(_ data: Data, account: String) throws {
        let query: [String: Any] = [
            kSecClass as String: kSecClassGenericPassword,
            kSecAttrAccount as String: account,
            kSecValueData as String: data,
            kSecAttrAccessible as String: kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly
        ]
        SecItemDelete(query as CFDictionary)              // overwrite jika ada
        let status = SecItemAdd(query as CFDictionary, nil)
        guard status == errSecSuccess else { throw KeychainError.status(status) }
    }

    static func read(account: String) -> Data? {
        let query: [String: Any] = [
            kSecClass as String: kSecClassGenericPassword,
            kSecAttrAccount as String: account,
            kSecReturnData as String: true,
            kSecMatchLimit as String: kSecMatchLimitOne
        ]
        var item: CFTypeRef?
        guard SecItemCopyMatching(query as CFDictionary, &item) == errSecSuccess else { return nil }
        return item as? Data
    }
}
enum KeychainError: Error { case status(OSStatus) }
Anti-PatternMenyimpan access token / refresh token di UserDefaults atau plist = kebocoran kredensial; keduanya tidak terenkripsi dan terbaca lewat backup. Token selalu di Keychain dengan accessibility ...ThisDeviceOnly agar tidak ikut ter-restore ke device lain. Hardening lanjutan (biometric gate) di Module 15.

05SwiftData & Core Data

Untuk model lokal relasional, ada dua pilihan resmi. Status 2026: SwiftData sudah production-ready untuk project baru berbasis SwiftUI; Core Data tetap unggul untuk object graph sangat kompleks, heavyweight migration, dan public CloudKit.

SwiftData — deklaratif, code-first
import SwiftData

@Model
final class CachedOrder {
    @Attribute(.unique) var id: String
    var total: Decimal
    var createdAt: Date
    @Relationship(deleteRule: .cascade) var items: [CachedItem]
    init(id: String, total: Decimal, createdAt: Date, items: [CachedItem] = []) {
        self.id = id; self.total = total; self.createdAt = createdAt; self.items = items
    }
}

// Setup container di entry point
@main struct MyApp: App {
    var body: some Scene {
        WindowGroup { ContentView() }
            .modelContainer(for: CachedOrder.self)
    }
}

// Query reaktif di View
struct OrdersView: View {
    @Query(sort: \CachedOrder.createdAt, order: .reverse) var orders: [CachedOrder]
    @Environment(\.modelContext) private var context
    var body: some View {
        List(orders) { Text($0.id) }
    }
}
Decision · SwiftData vs Core Data (2026)
Pilih SwiftData bila
  • Project baru, SwiftUI-first
  • Model & relasi wajar
  • Butuh kecepatan & boilerplate minimal
  • Sync iCloud privat
  • Concurrency via @ModelActor
Tetap Core Data bila
  • Object graph sangat kompleks (puluhan entity)
  • Heavyweight/custom migration
  • Public CloudKit database
  • Codebase UIKit besar yang sudah ada
  • Butuh kontrol granular & tooling matang
Catatan epistemik: SwiftData masih berevolusi; untuk app enterprise besar, banyak tim membungkusnya di Repository abstraction (Module 8–9) agar bisnis logic tidak terikat framework persistence — sehingga migrasi antar-framework di masa depan terisolasi. Verifikasi kapabilitas migration terbaru terhadap rilis SwiftData saat Anda mengevaluasi.

06Background Tasks

Kerja yang harus berlanjut saat app tidak di depan: refresh data, upload, sinkronisasi. iOS membatasi ketat demi baterai — gunakan API yang tepat.

KebutuhanAPI
Refresh berkala (app refresh)BGAppRefreshTask (BGTaskScheduler)
Pemrosesan panjang (maintenance, ML)BGProcessingTask
Download/upload besar yang bertahanURLSession background configuration
Eksekusi singkat saat ke backgroundbeginBackgroundTask
 
import BackgroundTasks

// 1. Daftarkan saat launch
BGTaskScheduler.shared.register(
    forTaskWithIdentifier: "com.app.refresh", using: nil) { task in
    handleRefresh(task as! BGAppRefreshTask)
}

// 2. Jadwalkan (mis. saat masuk background)
func schedule() {
    let request = BGAppRefreshTaskRequest(identifier: "com.app.refresh")
    request.earliestBeginDate = Date(timeIntervalSinceNow: 15 * 60)
    try? BGTaskScheduler.shared.submit(request)
}

// 3. Tangani — set expiration handler & tandai selesai
func handleRefresh(_ task: BGAppRefreshTask) {
    schedule()                                  // jadwalkan berikutnya
    let work = Task {
        try await syncLatest()
        task.setTaskCompleted(success: true)
    }
    task.expirationHandler = { work.cancel() }  // hormati batas waktu sistem
}
WajibIdentifier harus didaftarkan di Info.plist (BGTaskSchedulerPermittedIdentifiers) dan capability Background Modes diaktifkan. Selalu pasang expirationHandler dan panggil setTaskCompleted — task yang tidak diselesaikan akan dihukum sistem dengan penjadwalan lebih jarang.

EX 01

Generic GET

Lengkapi fungsi fetch generic yang mengambil URL, memvalidasi status, dan mendecode ke tipe Decodable apa pun.

▸ Lihat solusi & review 
func fetch<T: Decodable>(_ url: URL, as: T.Type = T.self) async throws -> T {
    let (data, resp) = try await URLSession.shared.data(from: url)
    try validate(resp)
    let dec = JSONDecoder()
    dec.keyDecodingStrategy = .convertFromSnakeCase
    return try dec.decode(T.self, from: data)
}

Review: Generic T: Decodable membuat satu fungsi melayani semua endpoint. Validasi status sebelum decode mencegah "decode error" menyesatkan padahal sebenarnya 401/500.

EX 02

Token round-trip Keychain

Simpan string token ke Keychain lalu baca kembali sebagai String.

▸ Lihat solusi & review 
func saveToken(_ token: String) throws {
    try Keychain.save(Data(token.utf8), account: "access_token")
}
func loadToken() -> String? {
    Keychain.read(account: "access_token").flatMap { String(data: $0, encoding: .utf8) }
}

Review: Token disimpan sebagai Data. Pastikan accessibility ...ThisDeviceOnly di save agar token tidak ikut backup/restore lintas device.
