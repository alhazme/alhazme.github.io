03Authentication: Bearer, Refresh, Interceptor

Pola universal: setiap request menyertakan Bearer token; saat 401, refresh token sekali, lalu ulangi request. Alamofire menyediakan RequestInterceptor (gabungan adapter + retrier) untuk ini.

final class AuthInterceptor: @unchecked Sendable, RequestInterceptor {
    private let tokenStore: TokenStore         // Keychain (Module 5)

    // ADAPT: sisipkan Bearer token ke setiap request
    func adapt(_ urlRequest: URLRequest, for session: Session,
               completion: @escaping (Result<URLRequest, Error>) -> Void) {
        var req = urlRequest
        if let token = tokenStore.accessToken {
            req.headers.add(.authorization(bearerToken: token))
        }
        completion(.success(req))
    }

    // RETRY: tangani 401 dengan refresh lalu ulangi
    func retry(_ request: Request, for session: Session, dueTo error: Error,
               completion: @escaping (RetryResult) -> Void) {
        guard let resp = request.task?.response as? HTTPURLResponse,
              resp.statusCode == 401 else { return completion(.doNotRetry) }
        Task {
            do { try await tokenStore.refresh(); completion(.retry) }
            catch { completion(.doNotRetryWithError(error)) }
        }
    }
}
Jebakan kritis: refresh stormJika 10 request gagal 401 bersamaan, jangan refresh 10 kali. Serialisasikan refresh: satu refresh in-flight, request lain menunggu hasilnya. Gunakan actor (Module 3) untuk men-coalesce refresh — ini mencegah server menolak refresh ganda dan race condition token.

04Retry Mechanism

Selain 401, retry juga relevan untuk kegagalan jaringan sementara (timeout, 5xx). Gunakan exponential backoff dengan batas.

func retry(_ request: Request, for session: Session, dueTo error: Error,
           completion: @escaping (RetryResult) -> Void) {
    guard request.retryCount < 3 else { return completion(.doNotRetry) }   // batas
    if let resp = request.task?.response as? HTTPURLResponse, (500...599).contains(resp.statusCode) {
        let delay = pow(2.0, Double(request.retryCount))                   // 1s, 2s, 4s
        completion(.retryWithDelay(delay))
    } else {
        completion(.doNotRetry)
    }
}
Aturan retryHanya retry operasi idempoten (GET, PUT, DELETE) secara default. POST (mis. pembayaran) tidak boleh di-retry buta — bisa menyebabkan transaksi ganda. Gunakan idempotency key dari server bila perlu meng-retry POST. Selalu batasi jumlah retry dan beri backoff agar tidak membanjiri server yang sedang bermasalah.

05Parsing: Nested JSON, Pagination, Error Model

API nyata mengembalikan struktur ber-envelope, paginasi, dan error model. Modelkan semuanya dengan Codable.

// Envelope + pagination umum
struct Page<T: Decodable>: Decodable {
    let data: [T]
    let meta: Meta
    struct Meta: Decodable { let page: Int; let totalPages: Int; let nextCursor: String? }
}

// Error model dari server
struct APIErrorBody: Decodable, Error { let code: String; let message: String }

func loadPage(cursor: String?) async throws -> Page<Order> {
    var url = "https://api.app.com/orders"
    if let cursor { url += "?cursor=\(cursor)" }
    return try await network.get(url)        // generic decode ke Page<Order>
}
Pagination di RepositoryLogika "ambil halaman berikutnya, gabung, hentikan saat nextCursor == nil" hidup di Repository — bukan di ViewModel. ViewModel hanya memanggil loadMore() dan menerima daftar gabungan. Ini menjaga presentation tipis dan pagination teruji.

06Abstraksi & Testability

Aturan inti seluruh modul: library tidak pernah bocor ke atas. Definisikan protocol; library hanya muncul di implementasinya.

// Domain/Core — kontrak, tanpa import Alamofire
protocol NetworkService {
    func get<T: Decodable>(_ path: String) async throws -> T
    func post<B: Encodable, T: Decodable>(_ path: String, body: B) async throws -> T
}

// Data — implementasi Alamofire (satu-satunya tempat import Alamofire)
final class AlamofireNetworkService: NetworkService { /* ... */ }

// Test — mock tanpa jaringan
struct MockNetworkService: NetworkService {
    var stub: Any
    func get<T: Decodable>(_ path: String) async throws -> T { stub as! T }
    func post<B: Encodable, T: Decodable>(_ path: String, body: B) async throws -> T { stub as! T }
}
HasilRepository & use case diuji dengan MockNetworkService — deterministik, tanpa jaringan, cepat. Mengganti Alamofire ke Moya atau kembali ke URLSession hanya mengganti satu implementasi. Inilah yang membuat stack networking Anda tahan-waktu & reusable lintas proyek.

EX 02

Coalesce refresh

Sepuluh request gagal 401 bersamaan. Rancang mekanisme agar token hanya di-refresh sekali.

▸ Lihat solusi & review 
actor TokenRefresher {
    private var inFlight: Task<Void, Error>?
    func refresh() async throws {
        if let inFlight { return try await inFlight.value }   // ikut yang sedang jalan
        let task = Task { try await performRefresh() }
        inFlight = task
        defer { inFlight = nil }
        try await task.value
    }
}

Review: actor menjamin akses inFlight aman. Request kedua–kesepuluh menunggu task refresh yang sama, bukan memicu refresh baru. Mencegah refresh storm & race token.

EX 03

Retry yang aman

Endpoint pembayaran (POST) gagal dengan timeout. Apakah boleh di-retry otomatis? Jelaskan.

▸ Lihat solusi & review

Tidak buta. POST tidak idempoten — retry bisa membuat pembayaran ganda. Solusi: minta server menyediakan idempotency key; retry hanya aman bila server men-deduplikasi berdasarkan key tersebut.

Review: Retry default hanya untuk operasi idempoten (GET/PUT/DELETE). Untuk POST kritis, idempotency adalah tanggung jawab kontrak API, bukan asumsi klien.

EX 04

Abstraksi anti-bocor

Seorang engineer menulis func fetch() -> DataRequest (tipe Alamofire) di protocol Repository. Apa masalahnya?

▸ Lihat solusi & review

DataRequest adalah tipe Alamofire yang bocor ke kontrak domain. Repository kini terikat Alamofire — tak bisa di-mock tanpa library, tak bisa ganti tool. Perbaiki: kembalikan tipe domain ([Order]) via async throws.

Review: Kontrak harus berbicara dalam tipe domain/Foundation, tidak pernah tipe library. Library berhenti di lapisan implementasi.
