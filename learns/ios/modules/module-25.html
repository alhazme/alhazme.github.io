01App Extension — Model Umum

iOS mendefinisikan banyak extension point (Widget, Share, Action, Notification Service/Content, Keyboard, dll.). Semua berbagi karakteristik inti yang wajib Anda pahami sebelum membangun salah satunya.

  • Proses terpisah — extension tak berbagi memori dengan app; komunikasi via App Group / shared container.
  • Siklus hidup pendek & dibatasi — sistem memberi waktu/memori terbatas; jangan lakukan kerja berat berkepanjangan.
  • Kode bersama via framework/paket — logika domain di modul bersama (M9), bukan diduplikasi antara app & extension.
  • Entitlement & Info.plist per-extension — tiap extension punya target, bundle ID, dan konfigurasi sendiri.
Anti-pattern(1) Menaruh logika bisnis penting hanya di dalam extension — sulit di-test & tak reusable; letakkan di paket bersama. (2) Mengasumsikan extension bisa berjalan lama / mengakses semua resource app — ia dibatasi. (3) Berbagi data lewat mekanisme selain App Group (mis. menulis ke Documents app utama) — takkan terlihat lintas proses.

02Share Extension

Share Extension membuat app Anda muncul di share sheet sistem — user membagikan URL/gambar/teks dari app lain langsung ke app Anda.

import UniformTypeIdentifiers

// Di dalam Share Extension: ambil item yang dibagikan
func handleShared(_ extensionContext: NSExtensionContext?) {
    guard let item = extensionContext?.inputItems.first as? NSExtensionItem,
          let provider = item.attachments?.first else { return }

    if provider.hasItemConformingToTypeIdentifier(UTType.url.identifier) {
        provider.loadItem(forTypeIdentifier: UTType.url.identifier) { data, _ in
            guard let url = data as? URL else { return }
            // Simpan ke App Group agar app utama memprosesnya nanti
            let d = UserDefaults(suiteName: "group.com.alhazme.app")
            d?.set(url.absoluteString, forKey: "pendingSharedURL")
            self.extensionContext?.completeRequest(returningItems: nil)
        }
    }
}
Kasus vertikal — "clip produk" / catat cepatE-commerce/UMKM: user melihat produk di Safari → share ke app Anda → Share Extension menyimpan URL ke App Group → app utama mengambil & memprosesnya (fetch metadata, simpan ke wishlist). Karena extension berumur pendek, pola yang benar: simpan minimal ke App Group, proses berat di app utama (atau via background task M5). Deklarasikan tipe konten yang diterima (NSExtensionActivationRule) agar app hanya muncul untuk konten relevan.

03SiriKit vs App Intents

Untuk integrasi Siri & otomasi, ada dua jalur. Memilih yang tepat penting agar tak membangun di atas API yang salah.

JalurKapanStatus
App Intents (M20)Mayoritas app baru — aksi kustom, Shortcuts, Spotlight, widget interaktifModern, direkomendasikan
SiriKit (Intents domain)Domain bawaan spesifik (messaging, VoIP, pembayaran, workout, media, ride)Untuk domain yang App Intents belum cakup
Old → New → AlasanOld: SiriKit dengan INIntent kustom (Intents/IntentsUI extension) untuk aksi umum. New: App Intents (Swift-native, tanpa extension terpisah untuk banyak kasus) — inilah yang sudah Anda pelajari di M20. Migration: untuk aksi kustom, gunakan App Intents; pertahankan SiriKit hanya bila memakai system intent domain bawaan (mis. app pesan/VoIP yang butuh integrasi telepon). Alasan: App Intents lebih sederhana, satu definisi melayani Siri + Shortcuts + Spotlight + widget, dan arah investasi Apple. Batas domain SiriKit vs cakupan App Intents berubah antar versi — verifikasi untuk kebutuhan spesifik Anda.

04MultipeerConnectivity

Komunikasi peer-to-peer tanpa internet — menemukan device terdekat lewat Wi-Fi/Bluetooth dan bertukar data. Ideal untuk skenario lokal/offline.

import MultipeerConnectivity

final class PeerSession: NSObject, MCSessionDelegate {
    private let peerID = MCPeerID(displayName: UIDevice.current.name)
    private lazy var session = MCSession(peer: peerID, securityIdentity: nil,
        encryptionPreference: .required)   // WAJIB enkripsi

    func send(_ data: Data) throws {
        guard !session.connectedPeers.isEmpty else { return }
        try session.send(data, toPeers: session.connectedPeers, with: .reliable)
    }
    // discovery: MCNearbyServiceAdvertiser + MCNearbyServiceBrowser
    // delegate: session(_:didReceive:fromPeer:) → terima data
    func session(_ s: MCSession, peer: MCPeerID, didChange state: MCSessionState) {}
    func session(_ s: MCSession, didReceive data: Data, fromPeer peerID: MCPeerID) {}
    func session(_ s: MCSession, didReceive stream: InputStream, withName n: String, fromPeer p: MCPeerID) {}
    func session(_ s: MCSession, didStartReceivingResourceWithName n: String, fromPeer p: MCPeerID, with progress: Progress) {}
    func session(_ s: MCSession, didFinishReceivingResourceWithName n: String, fromPeer p: MCPeerID, at localURL: URL?, withError e: Error?) {}
}
Keamanan & izin(1) Set encryptionPreference: .required — jangan kirim data tanpa enkripsi. (2) iOS terbaru menuntut string izin Local Network (NSLocalNetworkUsageDescription) + deklarasi Bonjour service; tanpa itu discovery gagal/crash. (3) Jangan percaya peer secara implisit — validasi & otorisasi data yang diterima (zero-trust: peer lain bukan berarti tepercaya). (4) Untuk data sensitif, lapisi enkripsi aplikasi sendiri (CryptoKit M21) di atas transport.
Kasus vertikal — POS/berbagi offline di lokasiLogistik/retail: dua device di gudang/toko bertukar data (transfer stok, sinkron pesanan) tanpa internet — berguna di area sinyal buruk. Atau berbagi katalog antar sales di lapangan. Tetap terapkan validasi & enkripsi; MultipeerConnectivity menyediakan transport, keamanan aplikatif tetap tanggung jawab Anda.

05PencilKit

PencilKit memberi kanvas menggambar/menulis tangan siap-pakai (PKCanvasView) dengan dukungan Apple Pencil, tool picker, dan low-latency inking.

import PencilKit

// UIKit canvas — bungkus via UIViewRepresentable untuk SwiftUI
func makeCanvas() -> PKCanvasView {
    let canvas = PKCanvasView()
    canvas.drawingPolicy = .anyInput          // Pencil + jari
    canvas.tool = PKInkingTool(.pen, color: .black, width: 4)
    return canvas
}

// Simpan hasil gambar sebagai data (persist ke file/App Group)
func exportDrawing(_ canvas: PKCanvasView) -> Data {
    canvas.drawing.dataRepresentation()       // simpan; muat kembali dengan PKDrawing(data:)
}

// Render ke gambar (mis. untuk tanda tangan di PDF, M23)
func renderImage(_ canvas: PKCanvasView) -> UIImage {
    canvas.drawing.image(from: canvas.drawing.bounds, scale: UIScreen.main.scale)
}
Kasus vertikal — tanda tangan, anotasi & ABK(1) Tanda tangan digital pada dokumen/kontrak: PencilKit → render ke gambar → sisipkan ke PDF (PDFKit M23). (2) Anotasi pada invoice/foto. (3) ABK: aktivitas menulis/mewarnai/tracing untuk latihan motorik halus — pasangkan dengan umpan balik multi-indera & target sentuh besar (aksesibilitas M17). Simpan PKDrawing.dataRepresentation() agar dapat dimuat & diedit ulang. Beberapa fitur (mis. dukungan latency/predictive) bergantung perangkat & versi — verifikasi bila kritis.

06Best Practice Lintas-Framework

  • Logika bersama, bukan di extension — domain di paket bersama; app & extension memakai kode yang sama (M8/M9).
  • Berbagi data via App Group — extension proses terpisah; simpan minimal, proses berat di app utama.
  • App Intents untuk aksi kustom — SiriKit hanya untuk system intent domain bawaan.
  • P2P: enkripsi wajib + zero-trust — encryptionPreference: .required, izin Local Network, validasi data peer.
  • PencilKit: persist dataRepresentation — dapat dimuat & diedit ulang; render ke gambar untuk tanda tangan/PDF.
  • Bungkus di balik protocol — SharedContentStore, PeerTransport, DrawingStore agar testable.
EpistemikCakupan App Intents vs SiriKit, persyaratan izin Local Network untuk MultipeerConnectivity, dan kapabilitas PencilKit berkembang antar versi iOS. Verifikasi terhadap dokumentasi Apple & WWDC terkini — contoh di modul ini menunjukkan pola stabil, konfirmasikan detail untuk iOS target Anda.

07Latihan

EX 01

Logika di extension

Share Extension Anda berisi seluruh logika parsing & penyimpanan produk. Kenapa ini keliru?

▸ Lihat solusi & review

Logika terkunci di extension: tak reusable oleh app utama, sulit di-test, dan extension berumur pendek (bisa mati sebelum selesai). Perbaiki: letakkan domain di paket bersama; extension hanya menyimpan input minimal ke App Group; app utama memproses.

Review: Extension = permukaan tipis. Build once — satu logika dipakai app & semua extension.

EX 02

Siri: jalur mana?

Anda ingin menambah perintah suara "Cek stok gudang". SiriKit atau App Intents?

▸ Lihat solusi & review

App Intents (M20) — aksi kustom, satu definisi melayani Siri + Shortcuts + Spotlight. SiriKit hanya bila memakai system intent domain bawaan (pesan, VoIP, pembayaran, workout, dll.), yang tak berlaku di sini.

Review: Default modern = App Intents. SiriKit adalah pengecualian untuk domain sistem tertentu.

EX 03

P2P tanpa enkripsi

Fitur transfer stok antar-device memakai MultipeerConnectivity dengan encryptionPreference: .none "agar lebih cepat". Risiko?

▸ Lihat solusi & review

Data (termasuk yang sensitif) dikirim tanpa enkripsi di jaringan lokal — dapat disadap. Set .required. Selain itu jangan percaya peer secara implisit: validasi & otorisasi data yang diterima; untuk data sangat sensitif, lapisi enkripsi CryptoKit (M21).

Review: Zero-trust + defense-in-depth berlaku juga di P2P. Transport terenkripsi adalah baseline, bukan opsi.

EX 04

Persist gambar PencilKit

Anda menyimpan gambar PencilKit sebagai PNG lalu ingin membiarkan user mengeditnya lagi nanti, tetapi guratan tak bisa diubah. Kenapa & fix?

▸ Lihat solusi & review

PNG adalah raster — kehilangan data guratan. Untuk edit ulang, simpan drawing.dataRepresentation() (PKDrawing) dan muat dengan PKDrawing(data:). Render ke PNG hanya untuk output final (tanda tangan di PDF, thumbnail).

Review: Simpan representasi vektor asli untuk editabilitas; raster hanya untuk presentasi akhir.

08Quiz, Mini-Project, Challenge & Referensi

Quiz Cepat

Jawab dulu di kepala, lalu buka jawaban.

Q1

Logika extension

Kenapa logika bisnis tak boleh tinggal di dalam extension?

▸ Jawaban

Extension berumur pendek (bisa mati sebelum selesai), tak reusable oleh app, dan sulit diuji. Letakkan domain di paket bersama; extension hanya menyimpan input minimal ke App Group; app utama memproses.

Q2

SiriKit vs App Intents

Untuk aksi kustom (mis. 'cek stok'), yang mana?

▸ Jawaban

App Intents — satu definisi melayani Siri + Shortcuts + Spotlight + widget. SiriKit hanya untuk system intent domain bawaan (pesan, VoIP, pembayaran, workout, media, ride).

Q3

MultipeerConnectivity

Apa dua hal wajib untuk P2P yang aman?

▸ Jawaban

encryptionPreference: .required (transport terenkripsi) dan validasi/otorisasi data dari peer (zero-trust — peer lain bukan berarti tepercaya). Plus izin Local Network + deklarasi Bonjour service.

Mini-Project

Bangun: share + tanda tanganBuat Share Extension yang menerima URL dari app lain → simpan ke App Group → app utama memproses. Tambahkan kanvas PencilKit untuk tanda tangan yang dirender ke gambar dan disisipkan ke PDF (M23). Tujuan: extension tipis + input Pencil.

Challenge

Naik levelTambahkan pertukaran data P2P (MultipeerConnectivity, enkripsi wajib, validasi peer) untuk skenario offline (mis. transfer stok antar-device). Tantangan: build-once logic + zero-trust P2P.

Common Mistakes

  • Logika bisnis terkunci di extension (tak reusable, rawan mati).
  • Kerja berat di extension berumur pendek (harusnya host app).
  • Custom SiriKit intent untuk aksi yang cukup dengan App Intents.
  • MultipeerConnectivity tanpa enkripsi / tanpa validasi peer.
  • PencilKit disimpan hanya sebagai raster (kehilangan editabilitas).
